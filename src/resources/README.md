# 资源导航

这里整理学习编程、查询文档、使用 AI 工具和搭建个人项目时经常会用到的网站。资源导航不追求把所有链接堆在一起，而是优先保留真正高频、可靠、适合反复查阅的入口。

## 使用建议

资源导航的价值不在于收藏很多网站，而在于遇到问题时知道应该先去哪里查。刚开始学习时，可以先用菜鸟教程这类入门网站建立整体印象；当需要确认细节、写生产代码或解决疑难问题时，再回到官方文档和权威资料。
