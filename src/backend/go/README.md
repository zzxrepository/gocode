# Go

这是 Go 的学习主线，按“语言基础 → 工程实践 → 服务开发”逐步展开。

## 学习路线

1. 基础语法：变量、类型、函数、结构体、接口、错误处理和模块管理。
2. 进阶能力：并发、Context、网络编程、测试和性能分析。
3. Web 开发：使用 Gin 构建 HTTP 服务。
4. 工程实践：配置、日志、数据库、缓存、鉴权和部署。
5. 微服务与分布式：以 go-zero 为主要实战框架。
