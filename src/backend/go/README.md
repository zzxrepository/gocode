# GO

这是 GO 的学习主线，先打好语言基础和进阶能力，再按框架与生态中的具体问题继续学习。

## 学习路线

1. Golang 基础知识：基础语法、项目结构、变量类型、数组切片、Map、指针、结构体、接口、错误处理和模块管理。
2. Golang 进阶知识：标准库、并发编程、Web 编程基础、工程实践和性能优化。
3. Golang 框架与生态：按 Web 框架、数据访问、微服务框架和常用库组织 Gin、GORM、go-zero、Viper 等内容。
