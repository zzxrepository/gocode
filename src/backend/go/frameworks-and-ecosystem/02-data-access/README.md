# 02. 数据访问

Go 程序访问数据存储时，需要处理驱动、连接池、查询、事务、模型映射和缓存一致性等问题。本专题涵盖 MySQL 驱动、`sqlx`、GORM 与 Redis 客户端的使用边界。
