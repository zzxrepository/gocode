# Golang 框架与生态

这里按解决的问题组织 Go 生态中的框架与常用库：Web 框架、数据访问、微服务框架和常用库。

“第三方依赖”说明代码的来源；“框架与生态”则说明它解决什么问题。Gin、GORM、go-zero 和 Viper 都需要通过 Go Modules 引入，但它们应分别放在与自身职责对应的栏目中。
