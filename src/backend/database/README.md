# 数据库

数据库栏目聚焦后端开发中最常用的数据存储与缓存能力。

- MySQL：基础、索引、事务、锁与性能优化。
- Redis：数据结构、缓存、持久化与常见应用场景。
- MongoDB：文档模型、索引、聚合与分布式存储。
