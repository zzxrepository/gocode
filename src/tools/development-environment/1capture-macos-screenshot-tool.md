# Mac 截图终于不用登录 QQ 了：1Capture，让截图、标注和分享一气呵成

![1Capture 截图与标注工具栏（图片来自 1Capture 官方文档）](https://mintcdn.com/1capture/RY7PB86hIR5xJUSF/cn/images/toolbar.jpg?fit=max&auto=format&n=RY7PB86hIR5xJUSF&q=85&s=c8155008d55c117bc5a9b8a35151f279)

## 前言

如果你和我一样，是从 Windows 切到 Mac 的用户，大概率会怀念过 QQ 截图。

以前在 Windows 上，`Ctrl + Alt + A` 一按，框选、箭头、文字、马赛克、序号标注，截完顺手贴到聊天框、文档或 Issue 里，整个过程几乎不用思考。真正让我离不开它的，并不是“能截图”这件事，而是它把**截图、说明问题、把结果发出去**连成了一件事。

上班以后换成 Mac，事情就微妙了：工作电脑没必要登录 QQ；有些公司的环境里，也不适合把 QQ 当作工作工具。macOS 自带截图当然够用，但当我需要给同事标一个 UI 问题、截一段很长的网页、把参考图固定在桌面上对照时，还是会觉得少了点 Windows 上 QQ 截图那种顺手的节奏。

我找过一圈 Mac App Store 里的截图工具，最后发现 **1Capture** 很接近我想要的感觉：它不是只帮你截一张图，而是尽量让截图之后的标注、整理、复制和交付都在同一个操作流里完成。对于经常写文档、提 Bug、做教程、和产品或设计同学沟通的 Mac 用户，这种“少切一次应用”的体验很值钱。

> 本文依据 1Capture 官方文档整理，并结合日常开发与内容创作场景介绍。功能和收费策略可能随版本调整，安装或购买前请以官方页面为准。

## 一、先说结论：它适合哪些人？

如果你的需求只是偶尔截一张图，macOS 自带 `Shift + Command + 4` 已经很好用；但下面这些场景，1Capture 会更有存在感：

- **开发者**：标出接口报错、页面样式问题或代码位置，再把图直接复制到 Issue、飞书、Notion 或 PR 评论里。
- **产品、测试、设计同学**：用箭头、备注、计数点表达修改意见，减少“你说的是左边那个按钮吗”的来回确认。
- **内容创作者**：将普通截图做成有背景、圆角和阴影的成图，用于文章、教程或社交媒体配图。
- **需要多窗口对照的 Mac 用户**：把截图、本地图片或剪贴板图片钉在桌面上，一边看参考内容一边操作。

它不需要依赖 QQ 登录，也不把截图限制在聊天软件里。这一点正好补上了工作 Mac 上的空缺。

## 二、三步开始：从安装到第一张截图

### 1. 从 Mac App Store 安装

打开 macOS App Store，搜索 **1Capture** 并安装即可；官方文档也提供了 App Store 下载入口。首次启动时，按系统提示完成相关权限授权。

### 2. 记住一个快捷键

按照官方当前文档，1Capture 默认通过连按两次 `Option` 键进入截图状态；在首次引导或设置面板中可以改成自己顺手的组合。忘记快捷键也没关系，点击顶部菜单栏的 1Capture 图标，同样可以开始截图。

对于从 QQ 截图迁移过来的人，我建议优先做一件事：**把快捷键改成肌肉记忆能接受的组合**。截图工具是否高效，关键就在于需要的时候能不能立刻唤起它。

### 3. 选区后再决定怎么截

进入截图状态后，1Capture 提供三种基础方式：

| 模式 | 怎么用 | 适合什么场景 |
| --- | --- | --- |
| 区域截图 | 拖拽选择需要的范围 | 截一段报错、一个按钮或一块内容 |
| 窗口截图 | 点击目标窗口 | 保留完整应用窗口，做问题反馈 |
| 全屏截图 | 按 `F` 选择当前屏幕 | 保存或标注整块屏幕内容 |

我觉得它比系统截图更顺手的一点是：**选区不是“一锤子买卖”**。选完以后仍能拖动调整范围；窗口截图则会限制在窗口边界内调整。截图边缘少了一列内容、尺寸想再精确一点，不需要从头再来。

## 三、它像 QQ 截图的地方，不只在于“能画箭头”

QQ 截图让人习惯的是“截完立刻说清楚”。1Capture 的核心体验也是这个：确定选区后，旁边会出现标注工具栏，悬停在图标上还能看到名称和对应的局部快捷键；完成标注后，可选择保存、复制、AirDrop 或钉图至桌面。

下面几个功能，是我认为最容易在工作中派上用场的。

### 1. 备注工具：把“这里有问题”说得更清楚

普通箭头能指向位置，但复杂问题往往需要补一句解释。1Capture 的备注工具可以先点出起始位置，再在空白区域放置文本框，形成带指向关系的说明。文本框样式和起始点样式还能继续调整。

这很适合提 UI Bug：

> 登录页在 1440px 宽度下，按钮与输入框的间距不一致；请和上方间距保持统一。

把文字直接压在界面上，往往会挡住信息；有指向的备注则能让图既清楚又整洁。

### 2. 计数点：多处反馈不用再画一堆箭头

当一张图里有多个问题时，计数点比连续画箭头更好读。1Capture 会按顺序添加数字点，并让输入的备注在导出的截图右侧依次展示。用在测试反馈、设计走查和教程步骤图上很合适：读者可以先看 1、2、3 的位置，再逐条读说明。

### 3. 箭头和取色：开发、设计沟通里的高频小工具

1Capture 的线条箭头支持直线、曲线和折线，也有更醒目的粗箭头。对于“请看这里”的快速反馈已经足够。

取色功能也值得单独提一下：进入截图状态后，光标旁会显示放大预览、屏幕坐标与颜色值；支持 Hex、RGB、HSL 三种格式，按 `Option` 切换格式，按 `C` 复制颜色。调前端样式、核对设计稿时，就不用再额外打开一个取色器。

### 4. 滚动截图：长页面终于不用手动拼图

文档、后台配置页、长聊天记录，最怕的就是内容太长。1Capture 支持纵向和横向滚动截图：框选区域后，从工具栏进入滚动截图模式即可。

- **纵向滚动**：将光标放在内容区域，缓慢滚动并观察预览缩略图；效果不理想可以重新截图。
- **横向滚动**：适合宽表格或横向内容，但需要触控板、妙控鼠标等支持左右滑动手势的设备。

截图完成后仍可继续标注、保存、AirDrop 或钉图，不用在“长图”和“标注”之间二选一。

### 5. 背景美化：把工作截图变成能直接放进文章的配图

做技术文章时，原始截图经常显得生硬：边缘太硬、留白不足、和页面背景不协调。1Capture 的背景美化可以给截图加纯色、渐变、桌面壁纸、艺术壁纸或自定义背景图，并调整填充、圆角、对齐、比例、模糊、阴影和边框等参数。

它的价值不是“把截图修得花哨”，而是用很少的操作，让图片更容易融入 CSDN、公众号或产品文档的版面。对我这种平时写教程的人来说，这个功能相当实用。

## 四、一个很有 Mac 味的能力：钉图至桌面

这个功能乍一看不如截图本身显眼，但实际用过就会发现很顺手。

1Capture 可以把截图、本地图片和剪贴板图片钉到桌面上。比如：

- 一边照着设计稿改页面；
- 一边对照接口字段或错误提示写代码；
- 把文章素材固定在旁边，避免来回切窗口；
- 将参考图片缩小并调低透明度，不挡住当前操作。

钉图后可以滚轮或触控板缩放；按住 `Command` 再滚动可调透明度（这两项也能在设置中互换）。右键可以旋转或翻转，按 `S` 可切换缩略图，按 `Z` 可切换回原始大小。它更像一张随手贴在桌面上的电子便签，特别适合多窗口工作流。

另外，除了截图，1Capture 还能标注本地图片：可以从菜单栏打开、把图片拖到菜单栏图标上，或在 Finder 中右键选择“打开方式 - 1Capture”。已有的产品图、截图素材，不需要重新截一遍也能继续加工。

## 五、免费与付费：这里要提前说清楚

软件好用是一回事，收费边界也应该说清楚。根据官方当前说明，1Capture 使用免费增值模式，并提供 7 天免费试用；试用结束后不会自动扣款。

以下功能在使用时会添加水印，付费后可去除：

- 数字点、备注、马赛克、放大镜、水印；
- 添加桌面背景、背景美化、滚动截图。

以下功能需要付费后使用：

- 钉图至桌面；
- OCR / QR（文字识别与二维码相关功能）。

因此，我的建议是：先用免费功能确认快捷键、选区和基础标注是否符合自己的习惯；如果你经常做长图、教程配图或桌面对照，再评估付费功能是否值得。这样比较踏实，也不会因为“以为完全免费”而产生落差。

## 六、我会怎么把它融入日常工作流？

如果你刚安装 1Capture，可以从下面这套最小习惯开始：

1. 设置一个不冲突、好记的截图快捷键。
2. 需要沟通的问题，优先用备注或计数点，不只截图不解释。
3. 截完直接复制到聊天、Issue 或文档，减少“先保存、再找文件、再上传”的步骤。
4. 写文章时，用背景美化统一截图的视觉风格。
5. 需要长期对照的内容，再考虑钉图至桌面。

真正提升效率的，从来不是工具栏里功能越多越好，而是常用路径足够短。1Capture 的思路刚好符合这一点：按下快捷键，选区，标注，复制或保存，事情就结束了。

## 总结

对 Windows 用户来说，QQ 截图难以替代的不是一个快捷键，而是它带来的连贯感。换到 Mac 后，如果不想为了截图专门登录 QQ，又希望保留“随手截、随手标、随手发”的工作方式，1Capture 是一个值得试试的选择。

它的基础截图、选区调整、备注、箭头、取色、本地图片标注等功能，能覆盖日常沟通；滚动截图、背景美化、钉图至桌面则进一步把它从“截图工具”推向了“信息表达工具”。当然，部分高阶能力有水印或付费门槛，先试用、再按自己的使用频率决定，才是最合适的方式。

如果你也在 Mac 上寻找一个接近 QQ 截图使用习惯的工具，不妨去 App Store 搜索 **1Capture**，亲自试一试它的截图节奏。
