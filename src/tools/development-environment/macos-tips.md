# macOS 使用技巧

## 一、文档结构说明

## 二、Mac 基础快捷键

### 1. 常用编辑快捷键

- `Command + C`（⌘C）：复制选中的文字、文件或内容。
- `Command + V`（⌘V）：粘贴复制的内容。
- `Command + X`（⌘X）：剪切选中的文字。
- `Command + Z`（⌘Z）：撤销上一步操作。
- `Command + A`（⌘A）：全选当前页面、文档或文件夹中的内容。
- `Command + S`（⌘S）：保存当前文件或文档。
- `Command + F`（⌘F）：在当前页面、文档或文件中查找内容。

### 2. App 和标签页操作

- `Command + Tab`（⌘Tab）：在已打开的 App 之间快速切换。
- `Command + W`（⌘W）：关闭当前窗口或当前标签页。
- `Command + Q`（⌘Q）：退出当前 App。
- `Command + T`（⌘T）：在浏览器、Finder、终端等应用中打开新标签页。
- `Command + 逗号`（⌘,）：快速打开当前 App 的设置或偏好设置。

### 3. Spotlight 搜索

- `Command + 空格`：打开 Spotlight 搜索。
- Spotlight 可以快速搜索并打开 App、文件、系统设置或网页结果。

## 三、系统、窗口与多任务管理

### 1. 窗口基础操作

- `Control + Command + F`（⌃⌘F）：按一次进入全屏，再按一次退出全屏。
- `Fn + Control + F`（fn⌃F）：将当前窗口填充到桌面大小，不会进入单独的全屏空间。
- `Command + M`（⌘M）：最小化当前窗口到程序坞。
- `Command + H`（⌘H）：隐藏当前 App 的所有窗口。
- `Command + Option + H`（⌘⌥H）：隐藏除当前 App 以外的其他 App 窗口。
- `Command + ~`（⌘~）：在同一个 App 的多个独立窗口之间切换，多个标签页不算。
- `Command + Option + D`（⌘⌥D）：显示或隐藏程序坞，也就是 Dock 栏。

### 2. 桌面和调度中心

- `Control + 上箭头`（⌃↑）：打开调度中心，查看所有窗口和桌面。
- `Control + 左箭头 / 右箭头`（⌃← / ⌃→）：在不同桌面之间切换。

### 3. 锁屏和系统设置

- `Control + Command + Q`（⌃⌘Q）：立即锁定 Mac 屏幕，适合临时离开电脑时保护隐私。
- 打开系统设置：按 `Command + 空格`，输入“系统设置”或 `System Settings`，按回车打开。
- 也可以点击左上角苹果菜单，选择“系统设置”。

### 4. 快速分屏和平铺窗口

#### 方法一：使用左上角绿色按钮

- 把鼠标移到窗口左上角的绿色按钮上，不一定要点击。
- 在弹出的菜单中选择“左侧屏幕”“右侧屏幕”或其他布局。
- 选择后，再点击另一个窗口，就可以让两个 App 并排显示。
- 如果想退出分屏，把鼠标移到顶部，重新点绿色按钮，选择退出全屏或移到桌面。

#### 方法二：按住 `Option` 查看更多窗口布局

- 把鼠标移到窗口左上角绿色按钮上。
- 按住 `Option`（⌥）键。
- 菜单里通常会显示更多布局选项，例如居中、填满桌面、移动和调整大小等。
- 适合不想进入全屏，只想快速整理窗口位置的时候使用。

#### 方法三：拖动窗口到屏幕边缘

- 拖住窗口标题栏，把窗口拖到屏幕左边、右边、上方或角落。
- 看到高亮区域后松开，窗口会自动贴到对应位置。
- 拖到左边或右边，通常变成半屏。
- 拖到角落，通常变成四分之一屏。
- 拖到菜单栏顶部，通常会填满桌面。

#### 方法四：按住 `Option` 拖动窗口

- 按住 `Option`（⌥）键。
- 同时拖动窗口到屏幕边缘或角落。
- 出现高亮区域后松开。
- 这个方式比普通拖动更容易触发窗口平铺。

#### 方法五：从菜单栏操作

- 点击屏幕顶部菜单栏中的“窗口”。
- 选择“移动与调整大小”或“全屏平铺”。
- 再选择左半屏、右半屏、上半屏、下半屏等布局。
- 适合不方便拖拽窗口时使用。

#### 如果拖拽分屏没有反应

- 打开“系统设置”。
- 进入“桌面与程序坞”。
- 找到“窗口”相关选项。
- 检查是否开启“将窗口拖到屏幕左边或右边缘以平铺”。
- 检查是否开启“将窗口拖到菜单栏以填充屏幕”。
- 检查是否开启“按住 ⌥ 键拖动窗口以平铺”。
- 如果不喜欢窗口之间有空隙，可以关闭“平铺窗口带有边距”。

### 5. 活动监视器和强制退出

- Mac 上类似 Windows“任务管理器”的工具叫“活动监视器”。
- 活动监视器可以查看 CPU、内存、能耗、磁盘、网络等占用情况。
- 打开活动监视器：按 `Command + 空格`，输入“活动监视器”或 `Activity Monitor`，按回车打开。
- 也可以从“启动台” -> “其他” -> “活动监视器”打开。
- 也可以在 Finder 中进入“应用程序” -> “实用工具” -> “活动监视器”。
- `Command + Option + Esc`（⌘⌥Esc）：打开“强制退出应用程序”窗口，适合快速关闭卡住的 App。

## 四、Finder 文件管理

### 1. 打开和搜索 Finder

- 点击程序坞中的 Finder 图标：最常用的打开方式。
- `Command + 空格`：打开 Spotlight，输入 `Finder` 或“访达”，按回车打开。
- `Command + Tab`：在已打开的 App 中切换到 Finder。
- `Command + N`（⌘N）：在 Finder 中打开新窗口。
- `Option + Command + 空格`（⌥⌘空格）：快速打开 Finder 搜索窗口，适合搜索文件、文件夹或本机内容。

### 2. 文件和文件夹操作

- `Command + Shift + N`（⌘⇧N）：在 Finder 中新建文件夹。
- `Command + Delete`（⌘⌫）：将选中的文件移到废纸篓。
- `Command + Shift + Delete`（⌘⇧⌫）：清倒废纸篓。
- `Return`（回车）：在 Finder 中选中文件或文件夹后，按回车可以重命名。
- `Command + I`（⌘I）：查看选中文件或文件夹的信息。

### 3. 预览、路径和显示选项

- `空格键`：在 Finder 中快速预览选中的文件。
- `Command + Option + P`（⌘⌥P）：在 Finder 中显示或隐藏路径栏。
- 路径栏可以看到当前文件夹所在位置，方便返回上级目录。
- 复制完整路径：选中文件后按住 `Option`，再右键文件，选择“将 xxx 拷贝为路径名称”。
- `Command + Shift + .`（⌘⇧.）：在 Finder 中显示或隐藏隐藏文件。
- `Command + /`（⌘/）：在 Finder 中显示或隐藏状态栏。
- 状态栏可以看到当前文件夹中的项目数量和可用空间等信息。

### 4. 移动文件或文件夹

#### 方法一：使用快捷键移动

- 在 Finder 中选中文件或文件夹，先按 `Command + C` 复制。
- 打开目标文件夹后，再按 `Command + Option + V`。
- 这样会把文件或文件夹移动到目标位置，相当于 Windows 里的剪切粘贴。

#### 方法二：使用三指拖移

- 在 Finder 中把鼠标指针移到文件或文件夹上。
- 用三根手指在触控板上拖动到目标文件夹或目标位置。
- 松开手指后，文件或文件夹就会被移动过去。
- 如果三指拖移没有反应，需要先到系统设置里开启“三指拖移”。

## 五、文本编辑与光标移动

### 1. 光标移动

- `Command + 左箭头 / 右箭头`（⌘← / ⌘→）：光标移动到当前行的开头或结尾。
- `Option + 左箭头 / 右箭头`（⌥← / ⌥→）：光标按单词移动。
- `Command + 上箭头 / 下箭头`（⌘↑ / ⌘↓）：光标移动到文档开头或结尾。

### 2. 选择、复制和查找

- `Command + A`（⌘A）：全选。
- `Command + C`（⌘C）：复制。
- `Command + V`（⌘V）：粘贴。
- `Command + X`（⌘X）：剪切。
- `Command + F`（⌘F）：查找。

## 六、触控板与手势

### 1. 基础点按和拖动

- 单指轻点或按下：点击按钮、链接、文件或输入框。
- 如果轻点没有反应，可以到“系统设置” -> “触控板”中打开“轻点来点按”。
- 单指双击：打开文件、文件夹或 App；在部分页面或图片中可以放大和缩小。
- 单指按住并拖动：拖移窗口、文件或选中文本。

### 2. 二指手势

- 二指轻点或点按：打开右键菜单。
- 二指上下滑动：滚动页面、列表、文档或网页。
- 二指左右滑动：在网页、图片、PDF 或部分 App 中前进和后退。
- 二指张开或捏合：放大或缩小网页、图片、地图或文档。
- 二指双击：智能缩放网页或 PDF 中的内容。
- 二指从触控板右边缘向左滑动：打开通知中心。
- 二指旋转：旋转图片或文档内容。

### 3. 三指和四指手势

- 三指拖移：可以直接拖动窗口、文件、文件夹或选中的文本。
- 在 Finder 中拖动文件或文件夹，相当于把它移动到目标位置。
- 开启路径通常是：“系统设置” -> “辅助功能” -> “指针控制” -> “触控板选项” -> 打开“使用触控板进行拖移”，并选择“三指拖移”。
- 开启后，部分三指手势可能会改成四指手势，按系统设置里的提示为准。
- 三指向上滑动：打开调度中心，查看所有窗口和桌面。
- 三指向下滑动：显示当前 App 的所有窗口。
- 如果三指向下没有反应，可以到“系统设置” -> “触控板” -> “更多手势”中检查“App Expose”。
- 三指左右滑动：在全屏 App 或多个桌面之间切换。
- 四根手指快速向中心捏合：快速打开启动台，也就是 App 页面集合。
- 拇指和三根手指张开：显示桌面，快速查看桌面文件。
- 三指轻点文字：查询词典、翻译或更多信息。
- 如果三指轻点文字没有反应，可以到“系统设置” -> “触控板” -> “光标与点按”中检查“查询与数据检测器”。

## 七、终端命令与命令行基础

- Mac 终端命令和 Linux 终端命令基本差不多：macOS 是类 Unix 系统，所以很多基础命令可以通用，但 Mac 多为 BSD 版本命令，部分参数可能和 Linux 不一样。

### 1. 目录与文件命令

- `pwd`：查看当前所在目录。
- `ls`：查看当前目录下的文件和文件夹。
- `cd <目录路径>`：切换目录，例如 `cd ~/Downloads`。
- `mkdir <文件夹名>`：创建文件夹，例如 `mkdir notes`。
- `touch <文件名>`：创建一个空文件；如果文件已存在，则更新它的修改时间，例如 `touch notes.txt`。

### 2. 文件查看和文本搜索

- `cat <文件名>`：查看文件内容，例如 `cat notes.txt`。
- `grep "关键词" <文件名>`：在文件中搜索文本，例如 `grep "error" app.log`。
- `grep -n "关键词" <文件名>`：搜索文本并显示匹配行号。

### 3. 用终端打开文件、文件夹和 App

- `open <文件路径>`：用默认应用打开文件。
- `open .`：打开当前目录。
- `open ~/Downloads`：打开指定文件夹。
- `open -a "应用名" <文件路径>`：指定 App 打开文件，例如 `open -a "Google Chrome" https://www.baidu.com`。
- `open -a "Visual Studio Code" .`：用 Visual Studio Code 打开当前目录。
- `open -R <文件路径>`：在 Finder 中定位并突出显示文件。
- `open -e <文件路径>`：用 TextEdit 打开文件。
- `open -n -a "应用名"`：打开一个新的应用实例。

### 4. 进程和系统状态

- `top`：实时查看 CPU、内存和进程占用情况，按 `q` 退出。
- 活动监视器是图形界面的进程查看工具，`top` 是终端里的进程查看工具。

### 5. 终端常用快捷键

- `Control + C`（⌃C）：在终端中中断当前正在运行的命令。
- `Control + Q`（⌃Q）：在终端中恢复被 `Control + S` 暂停的屏幕输出。

### 6. tmux 常用命令

- `tmux`：启动一个新的 tmux 会话。
- `tmux new -s 名称`：创建一个带名称的新会话。
- `tmux ls`：查看当前所有 tmux 会话。
- `tmux attach -t 名称`：重新进入指定会话。
- `tmux kill-session -t 名称`：关闭指定会话。
- `exit`：退出当前 shell，如果是会话中的最后一个窗口，会结束该 tmux 会话。

### 7. tmux 常用快捷键

- `Control + B` 后按 `D`：断开当前会话，让任务继续在后台运行。
- `Control + B` 后按 `C`：新建窗口。
- `Control + B` 后按 `N`：切换到下一个窗口。
- `Control + B` 后按 `P`：切换到上一个窗口。
- `Control + B` 后按 `%`：左右分屏。
- `Control + B` 后按 `"`：上下分屏。
- `Control + B` 后按方向键：在分屏之间切换。
- `Control + B` 后按 `X`：关闭当前分屏。
- `Control + B` 后按 `,`：重命名当前窗口。

### 8. screen 常用命令

- `screen`：启动一个新的 screen 会话。
- `screen -S 名称`：创建一个带名称的新会话。
- `screen -ls`：查看当前所有 screen 会话。
- `screen -r 名称`：重新进入指定会话。
- `screen -X -S 名称 quit`：关闭指定会话。
- `exit`：退出当前 shell，如果是会话中的最后一个窗口，会结束该 screen 会话。

### 9. screen 常用快捷键

- `Control + A` 后按 `D`：断开当前会话，让任务继续在后台运行。
- `Control + A` 后按 `C`：新建窗口。
- `Control + A` 后按 `N`：切换到下一个窗口。
- `Control + A` 后按 `P`：切换到上一个窗口。
- `Control + A` 后按 `"`：查看窗口列表。
- `Control + A` 后按 `A`：重命名当前窗口。
- `Control + A` 后按 `K`：关闭当前窗口。

### 10. tmux 常见使用流程

- 开始一个后台任务：`tmux new -s work`。
- 临时离开：按 `Control + B`，再按 `D`。
- 回来继续：`tmux attach -t work`。
- 查看还有哪些会话：`tmux ls`。
- 不想用了：`tmux kill-session -t work`。

## 八、软件安装与环境配置

### 1. 安装方式概览

- App Store：适合安装常见图形界面软件。
- 官网下载：适合安装浏览器、编辑器、网盘、专业软件等。

- `.pkg` 文件：安装向导式安装包，通常双击后按步骤安装。
- Homebrew：适合安装命令行工具、开发工具和部分图形界面软件。
