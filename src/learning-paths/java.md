# Java 学习路线

这条路线面向想从零建立 Java 后端能力的学习者。建议按阶段完成知识、代码练习和小项目，而不是只看概念。

## 第一阶段：Java 语言基础

学习变量、流程控制、面向对象、异常、泛型、集合与常用 API；同时熟悉 Maven 和 Git。

- 站内文章：[Java 基础语法与面向对象](/backend/java/basics)
- 练习目标：完成一个命令行通讯录或图书管理小程序。

## 第二阶段：集合、并发与 JVM

理解集合选择、线程池、锁、并发容器、JVM 内存结构与常见排查思路。

- 站内文章：[集合框架与并发编程](/backend/java/collections-and-concurrency)
- 站内文章：[JVM 与 Spring 生态](/backend/java/jvm-and-frameworks)
- 练习目标：实现一个带线程池和缓存的并发任务服务。

## 第三阶段：数据库与缓存

掌握 MySQL 表设计、索引、事务、Redis 缓存与 MongoDB 的适用场景。

- 站内文章：[数据库](/backend/database/)
- 练习目标：为项目设计订单、用户等核心数据模型，并做一次慢查询优化。

## 第四阶段：Web 与 Spring Boot

学习 HTTP、RESTful API、Spring Boot、数据访问、参数校验、鉴权、日志与测试。

- 站内栏目：[微服务与分布式](/backend/microservices/)
- 练习目标：完成一个可部署的 Spring Boot 后端项目。

## 第五阶段：分布式与云原生

在掌握单体服务之后，再学习消息队列、服务治理、分布式一致性、Docker、Kubernetes 与可观测性。

- 站内文章：[消息队列](/backend/message-queue/)
- 站内文章：[云原生](/backend/microservices/cloud-native)

> 建议：每阶段至少有一个可运行的小项目，再进入下一阶段；项目会把零散知识真正串起来。
