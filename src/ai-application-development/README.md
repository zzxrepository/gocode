# AI 应用开发

AI 应用开发覆盖从模型调用到可用产品的完整链路。

1. 大模型基础：模型选择、提示词、接口调用与 LangChain。
2. RAG：知识库构建、检索与生成。
3. MCP：工具接入与上下文协作。
4. Agent 应用开发：LangGraph 工作流、多工具协同与项目实战。
